# Pi Web Bridge Protocol message catalog

> Part of [pi-workflow-extensions](../README.md). Generated by `scripts/gen-bridge-protocol-catalog.mjs`. Do not edit by hand.

Protocol `pi-web-bridge` v1. Every legacy wire name maps to one catalog message; aliases remain until Phase 7.

| Message | Required capability | Meaning |
| --- | --- | --- |
| `settings.write` | `protocol.invoke:settings.write` | Write one setting. |
| `settings.models.write` | `protocol.invoke:settings.models.write` | Set scoped model patterns. |
| `trust.write` | `protocol.invoke:trust.write` | Save a trust decision. |
| `auth.login` | `protocol.invoke:auth.login` | Start a provider login. |
| `auth.answer` | `protocol.invoke:auth.answer` | Answer a login prompt. |
| `auth.logout` | `protocol.invoke:auth.logout` | Remove a provider credential. |
| `mcp.write` | `protocol.invoke:mcp.write` | Add, patch, override or remove an MCP server. |
| `session.prompt` | `session.write` | Send a user prompt to the live session. |
| `session.abort` | `session.write` | Abort the current turn. |
| `plugin.action.submit` | `protocol.invoke:plugin.action.submit` | Submit a declared action with its confirm string. |
| `session.set-model` | `session.write` | Change the session model. |
| `session.set-thinking` | `session.write` | Change the thinking level. |
| `web-command.dispatch` | `commands` | Dispatch a built-in web command. |
| `extension.web-command.dispatch` | `commands` | Dispatch an extension-declared web command. |
